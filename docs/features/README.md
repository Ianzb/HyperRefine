# 功能档案索引

> **文档定位**：这里只保存**单个功能**的行为、实现位置与验证记录。跨功能规范、接口签名、仓库地图不写在这里。
>
> 读法：先按功能选一篇，只读该篇；不要通读整个目录。通用开发规则从根目录 [`AGENTS.md`](../../AGENTS.md) 进入。

| 功能 | 档案 | 什么时候读 |
|---|---|---|
| 状态栏图标自定义 | [`STATUSBAR_ICON_CUSTOMIZATION.md`](STATUSBAR_ICON_CUSTOMIZATION.md) | 改图标模式、时钟 / 网速 / 电池布局、隐藏或着色 |
| 状态栏功能 | [`STATUSBAR_PORT.md`](STATUSBAR_PORT.md) | 查状态栏功能清单、移植记录与行为边界 |
| 通知功能 | [`NOTIFICATION_PORT.md`](NOTIFICATION_PORT.md) | 改通知卡片、HUN、滑动裁剪相关行为 |
| 壁纸压暗 | [`WALLPAPER_DARK_DIM.md`](WALLPAPER_DARK_DIM.md) | 改桌面 / 锁屏分别压暗、玻璃压暗 |
| 搜狗输入法玻璃材质（实验性，暂停） | [`SOGOU_IME_GLASS.md`](SOGOU_IME_GLASS.md) | 只读历史与失败原因；当前不作为可交付功能 |
| 第三方图标资源来源 | [`THIRD_PARTY_ICONS.md`](THIRD_PARTY_ICONS.md) | 核对预览图、主题图标资源与许可证 |

实验性功能的完整说明在 [`docs/experimental/`](../experimental/) 下，按目录内的 `EXPERIMENT.md` 读取，不在这里重复。
