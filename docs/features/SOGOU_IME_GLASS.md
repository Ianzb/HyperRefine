# 搜狗输入法玻璃材质（实验性，暂停开发）

目标包：`com.sohu.inputmethod.sogou.xiaomi`（小米商店版搜狗输入法）。

> 状态：1.15.0 起移至「实验性功能 → 搜狗输入法」，暂停开发。
> 框架层方案在真机上未产生可见效果，当前版本不保证生效；入口保留仅为后续定位渲染层，验证前请保持关闭。

## 功能

在「功能 → 实验性功能 → 搜狗输入法」提供：

| 配置 | 默认 | 说明 |
|---|---:|---|
| 键盘玻璃材质 | 关闭 | 总开关；关闭时完全恢复原生键盘 |
| 模糊半径 | 32 dp | 键盘根视图背景的 MIUI 模糊强度，0 关闭模糊 |
| 圆角半径 | 24 dp | 键盘根视图裁切圆角，0 关闭圆角 |

模糊与圆角互相独立；总开关关闭时两者都撤销。

## 实现边界

搜狗没有覆写 `InputMethodService.onCreateInputView`，键盘根视图由框架通过
`InputMethodService.setInputView(View)` 下发。因此模块只 hook 这个框架方法，不解析搜狗的混淆类名或布局 id：

1. `setInputView` 返回后，在键盘根视图上注册一次性布局监听，等宽高有效再应用。
2. 圆角：替换根视图的 `ViewOutlineProvider` 并开启 `clipToOutline`，保存并在关闭时恢复原始 provider / clip 状态。
3. 模糊：在根视图 `ViewGroup` 的索引 0 插入一个不可点击、不可聚焦的透明子 View，调用 MIUI 的
   `View.setMiBackgroundBlurMode` / `setMiViewBlurMode` / `setMiBackgroundBlurType` /
   `setBackgroundGradientBlurParams`；MIUI API 不可用时只保留圆角。
4. 根视图尺寸变化时重新应用模糊；关闭总开关时移除模糊节点并恢复圆角状态。

以上是已尝试的实现路径；真机上没有观察到可见的模糊或圆角变化，因此不再作为已生效能力宣传，后续需重新确认搜狗实际绘制的键盘层。

## 限制

- 这是第三方输入法的通用框架层处理，不复制搜狗官方主题，也不修改按键、候选词或输入逻辑。
- 玻璃观感取决于搜狗当前皮肤是否给键盘背景留出透明区域；完全不透明的皮肤下模糊只会出现在背景间隙，不会改变按键本身。
- 圆角通过裁切根视图实现；如果输入法窗口本身没有透明背景，圆角外侧可能显示窗口底色。
- 修改开关或滑条后需要重新打开键盘；已显示的键盘不会热更新。
- 只在小米定制包上声明作用域，其他搜狗包名不生效。
