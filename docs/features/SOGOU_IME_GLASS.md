# 搜狗输入法玻璃材质（实验性）

目标包为 `com.sohu.inputmethod.sogou.xiaomi`（搜狗输入法小米版）。入口为「功能 → 输入法 → 搜狗输入法」。同页的「剪贴板与常用语」分组提供常用语拖动排序。

| 配置 | 默认 | 说明 |
|---|---:|---|
| 键盘玻璃材质 | 关闭 | 控制键盘背景模糊和裁切圆角 |
| 模糊半径 | 32 dp | 为 0 时保留原皮肤底图 |
| 圆角半径 | 24 dp | 调整顶部工具栏的左上角和右上角，为 0 时使用原有轮廓 |

搜狗输入法小米版 10.32.21 的工具栏和按键区分别绘制皮肤底图。模块按实际视图坐标计算模糊范围，由工具栏、按键区和小米输入法底栏共用一个 Android 原生窗口模糊区域。工具栏描边沿上方两个圆角绘制。候选词、按键和底栏按钮沿用官方行为。

圆角与背景模糊可独立设置。系统关闭跨窗口模糊时保留原底图。关闭模块开关时恢复原始底图和工具栏轮廓。首次安装新版模块后需要重载搜狗进程。
